# Аудит переноса кистей, 2026-10-10

В Meta-адаптере исправлены две ошибки: неверный порядок вращений при нейтрализации кисти и ручная перезапись шести углов запястий после GMR. Live runtime передаёт в TWIST2 результат GMR; авторский actor, PD gains и частоты не менялись. Прямой wrist servo, ранее отклонённый пользователем, удалён.

## Математическая причина

Обозначим ориентации предплечья F(t), кисти W(t), относительную ориентацию R(t)=F(t)^-1 W(t), калибровочную R0=R(0), ориентацию нейтральной кисти G1 S. Старый код вычислял F(t) S R0^-1 R(t). Это поворачивает оси движения на калибровочную поправку. Теперь цель F(t) R(t) R0^-1 S = W(t) R0^-1 S: постоянное правое преобразование системы координат, сохраняющее мировое вращение.

Старая перезапись Euler-углов после GMR считала, что достигнутая ориентация предплечья равна исходной цели. При остаточной ошибке IK это искажало мировую ориентацию кисти. В новой версии GMR сам решает положение и ориентацию всей цепочки. Legacy поведение сохранено только для replay старых manifest; новые записи содержат wrist_frame_v2=true.

## Доказательства

- Независимая проверка native GMR против pinned Python GMR/Mink: 210 поз при трёх ростах, max tangent difference около 1e-13. Ошибка локализована в нашем Meta-адаптере.
- Регрессия на обеих руках, трёх мировых осях и двух направлениях вращения с ненулевой калибровочной поправкой: новая цель max error 4.04e-16 rad, достигнутая FK 5.08e-7 rad; старая формула ошибается на 0.171 rad. Проверка эквивалентных координат/масштаба/локальных осей: 2.23e-14.
- На старом полном эпизоде episode-1791621888465718, после исключения неизвестного начального blend, legacy команды совпадают с сохранёнными до 1.79e-7. Контроллерная ориентация сопоставлена с GMR одним фиксированным offset, привязанным к первой подходящей позе. Это проверка воспроизведения вращательного движения, не измерение абсолютного анатомического угла.

## Физика и ограничения

Два контрфактических 40-секундных прогона TWIST2 с выбранной quest-111586-500 начинаются с одинаковых измеренных qpos/qvel, но нулевой actor history/last action. Оба без падений и численных ошибок; ракетка не удерживается. Wrist joint RMS p95: 8.24° → 7.59°, медиана 4.18° → 4.53°. Root XY error p95 остаётся 1.65 м. Это не exact replay, не многосидовая оценка и не доказательство исправленной походки или живого отбивания.

Свежая автоматическая trace теперь включает target/actual wrist world quaternions, физические 29 суставов, корень, scene/policy/holder/calibration. Полный Y-эпизод по-прежнему нужен для входов Meta и полноценного анализа.
