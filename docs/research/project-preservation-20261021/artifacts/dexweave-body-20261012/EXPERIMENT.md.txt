# DexWeave body-only / Quest virtual legs — 12 октября 2026

Запрос: подготовить reference, реализовать и проверить body-only policy, обучить и сравнить с TWIST2. Работа ещё выполняется.

Основной источник ног — Meta virtual legs. Hand joints, предметы, APK и deployment не входят в эту серию. Код добавляется отдельным пакетом `training/dexweave` в checkout обучения; соседние незакоммиченные эксперименты не меняются.

## Зафиксированная постановка

- DexWeave v1, body-only: 157 actor / 286 critic / 29 actions, шесть anatomical tokens, PPO с нуля, 50 Гц control / 200 Гц training physics. Полного опубликованного авторского кода по повторной проверке нет.
- Основа среды для независимой реконструкции — официальный BeyondMimic `cd65172032893724b445448818c34165846d847d`, IsaacLab 2.1.0 / Isaac Sim 4.5.0. Это выбор реализации по статье, не утверждение о неизвестной точной версии среды DexWeave.
- Исходные frozen cuts: `outputs/quest-finetune-20261009/window-displacement/clamp-dataset`, 33 train / 12 validation. Оригиналы сохраняются. Held-out stages 2/9/14 никогда не идут в optimizer. Зеркала в первом сравнении не используются.
- Предварительно выбранный пилот по типу движения, до оценки результата: первый train clip длительностью не менее 10 с стадии 1 (ходьба), 8 (повороты), 13 (старт/стоп с руками впереди). Отдельная policy на reference соответствует постановке статьи. Первый завершённый запуск не будет называться общей политикой на все движения.
- Целевой полный протокол: 8000 итераций на reference; последние 1000 — сохранение каждые100 и пять evaluation seeds. До основного запуска обязательны настоящие optimizer/physics smoke и проверка вычислительного бюджета. Количество завершённых runs отражается отдельно.
- Сравнение с TWIST2 на тех же reference, начальных состояниях и временных окнах; сравнение на тренировавшемся reference — исполнение заданного навыка, не независимая генерализация. Существующий validation сохраняется для отдельных transfer probes.
- Training acceptance не останавливает PPO. Новых whole-run KL-stop/validation early-stop нет. GPU0–3 на проверке заняты; использовать только проверенные свободные устройства, по одному GPU на run.

## Неопределённости

Точная модель/PD DexWeave, часть head routing и контактных score-функций не опубликованы. Каждое выбранное дополнение отмечается в contract. Isaac Sim официально не поддерживает H100 без RT cores; отдельно проверяется headless physics. Успех старого Isaac Gym этого не подтверждает. MIPT SSH при первой попытке закрыл соединение; это не доказательство отсутствия доступных RTX-узлов.
