# DexWeave body-only в FURRY: подготовка и проверка

12 октября 2026. Основа — **Meta virtual legs**. Захват hand joints и проверка их информативности в эту работу не входят.

**Результат:** подготовлены референсы, реализован отдельный body-only actor и проверен настоящий PPO в Isaac Lab на 4096 средах. Рассчитан TWIST2 baseline. После восстановления SSH выполнен полный запуск; при распараллеливании обнаружена и исправлена ошибка adaptive phase sampler. Три пилота реально обучаются параллельно с исправленным sampler; для новых импортов модели выделены отдельные каталоги. Улучшение новой политики не установлено.

**Промежуточная оценка, 15:31 МСК:** checkpoint 1400 дал 14/15 завершённых прогонов против 15/15 у TWIST2. Мировая траектория на ходьбе/повороте точнее, скольжение хуже на всех трёх клипах. Один tracking failure на 3,04 с; доказательства улучшения общей походки пока нет. [Таблица и полный протокол](interim-1400-20261012/REPORT.md).

**Перекрёстная оценка 3×15:** зафиксированы checkpoints 2000/1800/1900, выполнены 225 прогонов по полной длине клипов. На отложенных клипах завершён 1/180 прогонов; перенос пока слабый. Построены [восемь хитмап и подробный отчёт](cross-eval-20261012-1248/REPORT.md).

Точный машиночитаемый статус: [status.json](status.json). Общий анализ применимости DexWeave: [исходный отчёт](../dexweave-feasibility-20261012/REPORT.md).

## 1. Согласованный body reference — подготовлен

Использован уже сохранённый непрерывный GMR на записях virtual legs. Не выполнен повторный сброс IK на границах клипов. Сохранены исходные cuts и разделение: **33 train / 12 validation**, стадии 2/9/14 остаются вне обучения.

Подготовлены 45 клипов на 50 Гц: 712,88 с train и 174,12 с validation. Сокращение относительно сетки 100 Гц связано с последним отсчётом при пересэмплировании. Оригиналы сохранены и проверены SHA256.

Каждый пакет содержит robot qpos, joint positions/velocities, именованные FK-позы и скорости 14 звеньев, исходные номера кадров, timestamps измерения/получения, ankle-позы virtual legs, flags и версии скелета. Полные исходные body-записи связаны с пакетом через проверенные hashes.

Опора предложена из исходных ankle-поз. Отдельных toe-поз в записи нет. Эти метки описывают предполагаемую кинематическую опору; измерением нагрузки стопы они не являются. Числовая уверенность не добавлялась.

На участках предполагаемой опоры выполнена коррекция: горизонтальная точка носка закреплена, перевод таза и суставы ног могут изменяться при соблюдении лимитов и пола. Ориентация таза, пояс, руки и запястья побайтно сохраняют исходный reference. Это наша адаптация к имеющимся данным.

| Проверка всех 45 клипов | Результат |
| --- | ---: |
| Ошибки решателя | 0 кадров |
| Максимальный сдвиг таза | 9,29 мм |
| Максимальная поправка сустава | 0,063 рад / 3,61° |
| Максимальная ошибка закреплённой XY-точки | менее 10⁻⁹ м |
| Проникновение стоп под пол | менее 10⁻⁹ м, численная точность |
| Изменение верхних суставов и ориентации таза | 0 |

**Нулевая скорость закреплённой точки — результат наложенного ограничения, а не доказательство улучшения походки.** Динамическая исполнимость определяется после обучения и rollout.

Для пилота заранее выбраны первые train-клипы длительностью ≥10 с в трёх типах движения:

## 2. Body-only actor и обучение — реализованы, smoke пройден

Добавлен изолированный пакет [training/dexweave](../../.tools/furry-training/prototypes/quest_g1/training/dexweave/README.md). Локальный HEAD `1523add` (исправления sampler и параллельного импорта; первый run использует `af88537`, различие — только временный каталог импорта); соседние незакоммиченные эксперименты не включены. Runtime Quest не менялся.

Actor принимает 157 значений, использует шесть anatomical tokens и выдаёт 29 действий. Два attention-блока, пять выходных голов, отдельный critic на 286 входов. Сеть actor содержит 586 653 параметра. Состояния и действия сопоставляются по именам суставов, независимо от порядка PhysX.

Обучающий стек: официальный BeyondMimic `cd65172032893724b445448818c34165846d847d`, IsaacLab 2.1.0 / Isaac Sim 4.5.0, RSL-RL 2.3.1, серверный Torch 2.5.1+cu124. Контроль 50 Гц, физика обучения 200 Гц. Отдельная политика на каждый reference, обучение с нуля. Новых whole-run KL-stop или остановки по регрессу validation нет.

| Проверка | Подтверждённый результат |
| --- | --- |
| Локальные тесты | 13 passed, включая 5 проверок sampler |
| Покрытие наблюдений regional encoders | все 157 входов, без пропусков/дублирования |
| Смена мировой системы координат | actor/critic observations инвариантны |
| PPO integration | 40 minibatch updates; actor и critic обновляются |
| Isaac Lab, G1, 4096 сред | 2 PPO iterations завершены, losses конечны, actor изменён |
| Фактический backend | GPU dynamics=true, broadphase=GPU, PhysX tensors=cuda:0 |
| FK Isaac Lab против reference, 4096 сред | max 0,032 мм |
| Экспорт smoke checkpoint | ONNX/PyTorch max error 9,54×10⁻⁷, 168 samples |
| ONNX → MuJoCo | 5 тестовых rollout выполнены |

Два PPO update проверяют работоспособность, а не качество. Smoke actor завершает tracking примерно через 0,4 с: это ожидаемо для практически необученной сети. Его меньшую ошибку на таком коротком префиксе нельзя сравнивать с десятисекундной ошибкой baseline.

H100 не поддерживает RTX-отрисовку Isaac Sim. Headless physics фактически работает. Импорт G1 зависал при построении окна URDF-импортера; в отдельном окружении отключены только GUI startup/shutdown. Парсер URDF и физика сохранены. [Hashes изменения SDK](server-evidence/urdf-headless-patch.json).

Доказательства: [тесты](network-tests.log), [4096-env status](server-evidence/status.json), [нативный контракт](server-evidence/native-contract.json), [экспорт](server-evidence/smoke-00002.json), [MuJoCo smoke](evaluation/dexweave-smoke.json).

## 3. Обучение и сравнение — три параллельных запуска

TWIST2 20k оценён на тех же трёх скорректированных reference, модели FURRY и пяти начальных условиях. Actor 50 Гц, физика 1000 Гц. Горизонт — первые 10 с каждого клипа; seed 0 стартует точно из reference, остальные добавляют суставной шум σ=0,005 рад. Catch-up servo не применяется.

| TWIST2, среднее по 15 rollout | Результат |
| --- | ---: |
| Завершение заданного горизонта | 15/15 |
| Физические падения | 0/15 |
| Ошибка таза XY в мире | 1,232 м |
| Ошибка звеньев после выравнивания yaw/XY | 3,41 см |
| Ошибка запястий в мире | 1,233 м |
| Скорость скольжения фактических контактных точек | 5,96 см/с |

Это показывает, почему завершение эпизода само по себе недостаточно: робот удерживается, но не воспроизводит мировое перемещение. Результат не является сравнением с уже обученным DexWeave. [Полные baseline trial metrics](evaluation/twist2-baseline.json).

Подготовлен [run_pipeline.sh](../../.tools/furry-training/prototypes/quest_g1/training/dexweave/run_pipeline.sh):

1. 8000 PPO iterations на reference, 4096 сред; одна политика на каждый клип.
2. Экспорт всех десяти checkpoint’ов 7100…8000.
3. По пять MuJoCo trials для каждого checkpoint и baseline на той же машине.
4. Сохранение completion, падений, world drift, ошибок рук и contact-point slip; отдельно — сравнение на общем пережитом префиксе.
5. Усреднение всего финального окна, без выбора удобного checkpoint.

Первоначально три run были поставлены последовательно на единственную свободную GPU 7. После освобождения ресурсов два остальных запущены параллельно. На stage08 обнаружена ошибка нашей реализации capped probabilities: насыщенные фазы повторно участвовали в перераспределении, из-за чего проверка лимита могла ошибочно остановить обучение. Исправление сохраняет насыщенные фазы фиксированными; результат проверен независимым численным решением для равномерных и сильно концентрированных весов, 4/10/18/30 фаз. Всего 13 тестов прошли. [Протокол тестов](sampler-fix-tests.log).

Для единообразного сравнения все три пилота перезапущены с исправлением под именами `full-stage01-v2`, `full-stage08-v2-importfix`, `full-stage13-v2-importfix` на GPU 7/6/5. Прежние логи и checkpoints сохранены в исходных каталогах. Первый запуск до исправления уже выполнял PPO; его прогресс не перенесён в новые runs. Два дополнительных run повторно запущены с уникальным временным каталогом URDF: стандартный путь IsaacLab зависит от времени до секунды и seeded RNG, что вызвало коллизию при одновременном старте. Первый исправленный run продолжился без нового перезапуска. Модель и параметры физики сохранены. Измеренная скорость была около 2,6–2,8 с/iteration. Предварительный ориентир — 6–7 часов от исправленного параллельного запуска плюс оценка.

Перед запуском на сервере повторно проверены hashes трёх NPZ, модели и TWIST2. Серверный экспорт smoke checkpoint: max ONNX/PyTorch error 1,07×10⁻⁶ на 168 samples; оба пути оценки — DexWeave и TWIST2 — выполнены. [Экспорт на сервере](server-evidence/server-export-smoke.log), [серверная оценка](server-evidence/server-eval-smoke.log). Снимок проверки: full-stage01-v2: 92/8000, full-stage08-v2-importfix: 12/8000, full-stage13-v2-importfix: 15/8000. Все три actor обновляются, PhysX работает на GPU, FK проверен. [Состояние параллельных запусков](server-evidence/parallel-verified/queue-state.json). Завершённых полных обучений пока нет.

## Что пока отличается от авторов

Это независимая реализация по [статье](https://arxiv.org/html/2609.34724v1): в [публичном репозитории DexWeave](https://github.com/WU-CVGL/DexWeave) авторский trainer/веса отсутствовали при проверке.

- Исходный body reference — наши virtual legs/GMR с контактной коррекцией; авторский полный retargeter не опубликован.
- Используется body-модель и PD из pinned BeyondMimic. Inspire hands, их payload/COM randomization и hand-load compensation отсутствуют в body-only адаптации.
- Неописанные детали routing голов waist/arms, положения LayerNorm и выполнения pre-roll выбраны явно и записаны в contract.
- Сравнение с TWIST2 оценивает целые контроллеры с их интерфейсами и PD, не изолированный выигрыш Transformer над MLP.
- Политика на одном reference не является общей политикой для произвольного движения. Независимая генерализация и живая работа на Quest не проверены.

Следующая проверяемая веха — завершённые full runs и итоговый `comparison.json` для каждого клипа. APK и установка на шлем в эту работу не входят.
