## Реализация

Добавлен отдельный backend `dexweave_body_v1`: 157 входов, 29 выходов, 50 Гц, встроенная в ONNX нормализация, точный порядок наблюдений, PD и ограничения скорости целевых суставов из Python evaluator. В истории хранится применённое действие. Отдельная физика MuJoCo — 1000 Гц. Моторные параметры установленной stand-сцены совпадают с frozen evaluation model по проверенным armature/damping/friction/joint ranges/control/force ranges.

Политика получает абсолютную GMR-позу и FK torso anchor. Внешний TWIST-сервоконтур скоростей для DexWeave не применяется; меню явно показывает абсолютную GMR-цель. Глобальная настройка догоняния для остальных политик сохранена. Записи содержат identity/копию весов и `dexweave-reference.csv` с фактическими входными абсолютными позами и скоростями. Прежний dynamic replay явно отклоняет этот backend, чтобы не выдавать TWIST-replay за правильный DexWeave; отдельный reader нового потока пока не реализован.

## Ограничения живого режима

**Живой вход ещё не эквивалентен обработанному датасету.** Offline support projection из обучения/оценки пока отсутствует в live. Скорости суставов вычисляются причинной обратной разностью 50 Гц, тогда как offline использовалась центральная разность с будущим кадром. Сохранён текущий Quest adapter/режим кистей, поэтому перенос offline-метрик на live не подтверждён. Обе политики помечены экспериментальными. Это установка для проверки, не приёмка походки.

Запрос запуска приложения отправлен, но система показывает `LaunchCheckControllerRequiredDialogActivity`; процесса приложения на последней проверке нет. **Native startup новой сборки и живая ходьба не подтверждены.** Для старта нужны активные контроллеры/пробуждение Quest.

Исходники изолированы в `project/`, изменения сохранены в `dexweave-runtime.patch`; другие рабочие копии не изменялись, публикации в GitHub нет. Предыдущий APK и настройки доступны по `base.json` и `menu-settings-before-install.txt`.
