## Постановка

V1 исключал низкие переносы порогом высоты и был остановлен до первого
обновления actor. V2 штрафует фактически движущуюся низкую стопу без
классификатора фаз, порога высоты референса или маски фактического контакта:

```text
C = 1 − exp(−Σfeet max(0, 0.065 − h_sole)² · tanh(2 · |v_centroid_xy|) / 0.05)
reward = −1.0 · dt · C, dt = 0.02 s; dt применяется один раз.
```

`h_sole` — минимальная высота физических сфер подошвы над плоскостью,
с учётом поворота и радиуса. Скорость — разность мировых положений центра
этих сфер с номинальным интервалом 20 мс. Неподвижная стопа не получает штрафа; подъём выше цели
не тянет её вниз. Низкий референс не уменьшает целевой просвет.

Основа — опубликованная [функция Unitree foot_clearance_reward][reward]
и [конфигурация G1][config] на commit
`4960b84732b0c2ec593dccbfe963fda1bcd7b1e3`. Исходная формула использует
симметричную ошибку высоты ankle-link относительно 0.1 м, вес +1,
`tanh(2 · speed)` и знаменатель 0.05, не его квадрат.
В нашей sphere URDF горизонтальная подошва ниже ankle-link на 35 мм:
100 − 35 = 65 мм. Это параметр reward, не фиксация позы. Для наклонённой
стопы минимальная высота всей подошвы строже исходной высоты ankle-link.
Односторонний дефицит, отрицательная ограниченная награда, физическая
подошва и скорость одной геометрической точки — исследовательская адаптация,
а не точное воспроизведение исходного reward. Проверенные SHA256 первичных
файлов сохранены в [EXPERIMENT.json](EXPERIMENT.json).

Treatment также заменяет скорость центра стопы скоростью контактной точки
в исходном штрафе скольжения, сохраняя его scale. Он действует на все
фактические контакты с полом независимо от фазы. Оценка контакта использует
силу тела и геометрическую близость к полу в сцене с одним роботом и плоскостью;
это не точные пары контактов решателя на 1000 Гц. Матрица проверяет два
изменения совместно и не разделяет их вклад.

## Сопоставимость

Оба условия используют те же данные, mapping ретаргетинга и исходную
инициализацию `111260/1000 comparison-baseline.pt`. Прототип root-morph
в данные не внесён. В каждой группе 4096 сред, 1000 actor updates,
сохранение и оценка каждые 250; actor input 1432, critic input 1743.
Шесть признаков фаз V1 удалены из обеих групп. Новый critic и optimizer
получают одинаковый warmup. Исходные TWIST2 PPO, LR, adaptive KL,
learnable std, DR, termination и imitation reward сохранены; новых правил
остановки обучения нет. Общие nonlooping, sphere URDF и оконная награда
перемещения/поворота остаются прежними.

Все четыре run ID, hashes checkpoint/датасета и параметры зафиксированы
в [EXPERIMENT.json](EXPERIMENT.json). Поле `matrix.gpus = [0,1,2,3]` и
команда `dispatch_clearance.py launch` описывают первоначальный одновременный
dispatch. Текущий план — отдельная очередь на свободные GPU; её оркестратор
не меняет trainer/evaluator. Эти сохранённые поля не означают резервирование
GPU или подтверждённый запуск.

## Оценка и ограничения

Фактическая скорость допускает обход штрафа остановкой стопы. Поэтому
снижение clearance cost или скольжения само по себе не считается успехом:
сравнение проверяет падения, выживание, root XY, направленный прогресс таза
и стоп в XY, оконное перемещение, heading, lateral error и верх тела.
Неопределённый прогресс при недостатке движения не считается улучшением.
Увеличение ошибки ног по Z и общей joint/key RMSE остаётся диагностикой:
подъём стоп выше низкого референса — намеренная свобода эксперимента.
Исходная imitation reward при обучении при этом не меняется.

Скольжение по замыслу и поворот вокруг смещённой точки опоры могут получить
штраф. V2 не распознаёт намерение шага. Старые trip-метрики с порогом высоты
референса — лишь частичная диагностика и не участвуют в основном решении.
Validation из 12 клипов уже многократно изучалась и не является независимым
test. Свежая baseline содержит 24 прогона и пригодна для повторного
использования только при совпадении policy/assets/data/evaluator fingerprint.
Автоматического деплоя нет.

Upstream reset дополнительно вызывает `simulate` для всех сред. Поэтому
фактический интервал между положениями подошвы при таком переходе может
превышать номинальные 20 мс, и разностная оценка скорости может быть
завышена. R1 исправляет только начальную проверку буферов; временная схема
reward и исходный reset в этом ограниченном эксперименте не менялись.
