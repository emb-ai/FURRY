# Видео оператора

Меню → «Вид» → «Записать видео оператора». Подтвердите системный запрос Quest.
Когда появится VIDEO REC, закройте меню или продолжите симуляцию. Для завершения:
«Вид» → «Остановить видео оператора». Дождитесь «Видео сохранено».

Файл: Movies/G1Quest/operator-YYYYMMDD-HHmmss-SSS.mp4, H.264, 1024×1024,
30 кадров/с, 8 Мбит/с, без звука (около 60 МБ/мин). Можно забрать по USB или:

```sh
adb pull /sdcard/Movies/G1Quest ./operator-videos
```

Видео поступает из системного композитора Horizon OS через MediaProjection.
Это моноскопическая видеоверсия вида шлема, включая показанные приложением меню;
поле зрения/масштабирование выбирает системный композитор.

Во время запроса и записи видео приложение расширяет обе проекции симметрично
минимум до ±57°. Одинаковая проекция используется при отрисовке и отправке слоя
OpenXR. После записи возвращается исходное поле зрения каждого глаза.
Это устраняет внутренний обрез виртуальной сцены в широком захвате;
плотность пикселей на угол во время записи уменьшается.

Для широкого захвата 110° на проверенной прошивке Quest использовались
`debug.oculus.captureFovDegrees=110` и `debug.oculus.headsetOverride=1`.
Приложение эти системные свойства не меняет; они сбрасываются после перезагрузки.
Перед применением проверьте, что нет других `debug.oculus.eyeFov*` overrides,
сохраните прежние значения обоих свойств и остановите запись:

```sh
adb shell getprop debug.oculus.captureFovDegrees
adb shell getprop debug.oculus.headsetOverride
adb shell getprop | grep 'debug.oculus.eyeFov'
adb shell setprop debug.oculus.captureFovDegrees 110
adb shell setprop debug.oculus.headsetOverride 1
```

Для отката восстановите сохранённые значения. Проверяйте результат новым MP4:
чтение свойств само по себе не подтверждает поле зрения композитора.
В живой записи 15 октября 2026 года (47.32 с, 1024×1024) подтверждены
passthrough, работа записи и устранение прежнего обреза справа/снизу.
Точное совпадение с бинокулярным видом через линзы не измерялось;
видимость ракетки во всех позах и на других прошивках не гарантируется.

Запись видео независима от Y/записи траекторий. Пауза симуляции, смена вида и
открытие меню её не останавливают. MP4 не добавляется в архив эпизода, не имеет
покадровой синхронизации с CSV и не используется автоматически для обучения.
При выходе из приложения, отзыве разрешения или другой MediaProjection-сессии
файл закрывается. При нехватке места запуск отклоняется; запись завершается
при лимите 4 ГБ или остатке ~256 МиБ. Успешно закрытый MP4 проверяется по duration
перед публикацией в MediaStore. После аварийного завершения процесса/питания
возможен незавершённый скрытый файл: восстановление после crash не реализовано.

NativeActivity заменена подклассом QuestActivity; прежнее имя компонента
android.app.NativeActivity сохранено через activity-alias. Сборка компилирует
Java и DEX; native ABI, физика, сцены и веса сохранены. Запись не запускается
автоматически, микрофон и внешняя камера не запрашиваются.

Источники: [Meta MediaProjection](https://developers.meta.com/vr/documentation/native/native-media-projection/),
[Android MediaProjection](https://developer.android.com/media/grow/media-projection).
